The first set of 2026 updates focused on compatibility and account management.

## What is new

- Added support for XML attachments.
- Updated plan change behavior so organizations keep a single active plan during transitions.
- Removed the extra contact step from the plan change page to make subscription changes more direct.
- Added support for DWG attachments.
- Introduced safeguards to prevent re-sending messages that are already delivered, bounced, or marked as spam.
- Offloaded outgoing HTML bodies to object storage to reduce database pressure at scale.
- Refreshed chart colors for improved dashboard readability.

Happy Sending!
